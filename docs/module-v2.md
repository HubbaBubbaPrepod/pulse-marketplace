# Пакеты модулей v2

Валидатор принимает schema/protocol2 наряду с прежним v1. Маркер обнаружения остаётся schema1: он задаёт репозиторий, ID и asset; версию протокола определяет сам пакет. Сканирование и модерация не запускают бинарники, не выдают права и не публикуют версию автоматически.

Пакет v2 описывает1–16 компонентов Agent/Monitor с полями, бинарниками, требуемыми разрешениями, объявлениями interval/manual/event и необязательными представлениями/действиями. Каталог сохраняет очищенные метаданные компонентов, объявленные среды/разрешения/триггеры, точный SHA-256 JSON и происхождение. Бинарников в ответах метаданных нет. Прежние снимки v1 не меняются.

Проверка отклоняет неоднозначные/нулевые/неизвестные поля, ID компонентов с конфликтом регистра, неверные хеши/платформы, триггеры/значения по умолчанию и метаданные сверх2 MiB, которые Monitor не сможет прочитать. Ограничения бинарников прежние:16 MiB на файл,48 MiB суммарно и68 MiB тело запроса. Проверка формата не гарантирует совместимость: новый Monitor поддерживает interval/manual, а события относятся к следующему этапу. Старые Monitor/Agent не объявляются совместимыми с v2.

Публикация требует прежнего независимого рассмотрения. GitHub-релиз v2 сам себя не одобряет. Ручной импорт JSON работает без подключения каталога. Нативный код выполняется с привилегиями хоста, без песочницы; одобрение и хеш не гарантируют безопасность.
