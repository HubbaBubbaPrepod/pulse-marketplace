# Публикация от организации

Организация управляет публичным репозиторием и явно делегирует публикацию участникам. В `pulse-marketplace.json` основной ветки добавьте числовые GitHub ID пользователей, а не имена:

```json
{
  "schemaVersion": 1,
  "moduleId": "example",
  "packageAsset": "module.json",
  "publishers": ["12345678"]
}
```

До 20 уникальных ID-строк; ID берётся из официального GitHub API профиля. Для тем добавьте `kind: "theme"`. Один маркер описывает один модуль или одну тему. Издатель входит через свой GitHub; основной маркер контролирует организация. Поле author внутри пакета не доказывает права на репозиторий.

Сканер обновляет делегирование при проверке основной ветки. Удаление ID или маркера отзывает права после следующего цикла; приватный кабинет не принимает делегирование старше 35 минут без успешного обновления. При проблемах GitHub доступ закрывается, а опубликованные пакеты сохраняются. Ручная отправка репозитория перечитывает маркер непосредственно с GitHub.

Каждая версия по-прежнему проходит проверку и модерацию. В ревизии сохраняется список издателей на момент обнаружения. Модератор из исходного или текущего списка не может одобрить эту версию. Администратор сохраняет ранее согласованное право одобрять собственные версии с обязательным комментарием и аудитом. Делегирование не назначает роли в Marketplace и не расширяет OAuth scopes.
